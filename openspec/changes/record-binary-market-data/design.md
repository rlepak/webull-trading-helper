## Design
Use the sibling bots' format: a big-endian four-byte positive length followed by UTF-8 JSON bytes. This is framed binary storage, not compression. Schema version 1 contains recordingId (UUID per writer run), sequenceNumber (monotonic per run), receivedAt (Chicago ISO offset with nanoseconds), and event (the complete typed event, including original provider fields). The pair recordingId/sequenceNumber distinguishes restarts. Maximum record size is 16 MiB.

Use data/{premarket,market,aftermarket}/MM-dd-yy/webull-HH.bin based on receivedAt converted with the shared application Clock zone. Use the same 03:00, 08:30, 15:00 boundaries as selection. One file contains all symbols and event types. At 08:30 both session folders can contain an 08 file. At the fall DST repeat, append both occurrences to the same hourly file; exact offsets and sequence preserve ordering.

A single bounded queue and worker preserve enqueue order. Serialize and assign sequence under one lock; the worker alone owns file output. Flush buffered output and FileChannel.force(false) at least every configured interval during healthy operation and on rotation/shutdown. Enqueue is not a durability acknowledgment; abrupt termination may lose the unflushed window. Queue overflow or I/O failure is terminal and prominently logged without raw events or secrets; later writes are rejected, never silently claimed saved.

Acquire a directory-level file lock before accepting records to prevent concurrent writers. On file reopen, scan framing and JSON envelopes; truncate only an incomplete final frame after warning, preserving complete records. Invalid lengths, invalid complete JSON or incompatible schema fail closed. Never overwrite a complete record. The lock persists until worker cleanup. Lifecycle starts before streaming and stops after streaming so shutdown drains admitted events. Disabled mode creates no files.

Use binary-log.enabled, directory, queue-capacity and flush-interval-ms in the existing application.properties. Default disabled for unconfigured installations; enable locally. Exclude data/ from Git. The replay reader/runtime and scanner/control-event parity are explicitly outside this writer-only increment.
